# Hermes Storage Policy

`D:\Hermes` remains intentionally outside OneDrive and ordinary cloud backup.

The user has explicitly authorized a controlled GitHub bridge to `https://github.com/orca1space/orca1store`.

The GitHub bridge is permitted only when the repository is private and only after the local exclusion rules are applied. API keys, passwords, tokens, local model files, runtime logs, caches, uploads, and generated archives must remain on the laptop and must never be committed.

Do not move this folder into OneDrive. Do not synchronize the excluded local data with any cloud service.
