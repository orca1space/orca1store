# Hermes / OrcaMax Code

## Local-first AI agent repository

هذا المستودع هو الجسر البرمجي والمرجع المحلي لمشروع **Hermes / OrcaMax Code**. يحتفظ بالمكونات البرمجية، المهارات، الاختبارات، والتوثيق اللازمة لتشغيل الوكيل محليًا على جهاز المستخدم.

> **قاعدة الاستقلال:** التشغيل الأساسي محلي، والبيانات التشغيلية لا تُزامَن تلقائيًا مع GitHub أو أي خدمة خارجية.

## ما يحتويه المستودع

| القسم | الوظيفة |
|---|---|
| `core/` | محرك الوكيل، واجهة API، المعرفة، الذاكرة، البحث، المحتوى، تحقيق الدخل، الموافقات، سير العمل، وجسر التعلم |
| `skills/` | سجل المهارات والمهارات المحلية القابلة لإعادة الاستخدام |
| `training/` | مكونات التدريب والحالة المهيأة للتشغيل المحلي؛ لا تُرفع حالات الجلسات أو الأسرار |
| `data/` | المعرفة المرجعية والاختبارات المسموح بها فقط؛ ملفات الحالة والنتائج التشغيلية مستثناة من Git |
| `bin/` | الأدوات المحلية مثل Probe وTree-sitter عندما تكون موجودة في النسخة المحلية |
| `vendor/` | الحزم المحلية المثبتة اللازمة للتشغيل دون اعتماد وقت التشغيل على الإنترنت |
| `docs/` | وثائق البنية، الجسر، التشغيل، وسياسة البيانات |
| `OrcaMax.bat` | مشغل واجهة OrcaMax على Windows |
| `hermes.bat` | مشغل Hermes المحلي |

## القدرات المدمجة

يتضمن المشروع تكاملات محلية لـ OCR، وتحويل المستندات، وفهرسة المعرفة، وتحليل الشيفرة، وأتمتة المتصفح المقيدة بالنطاق المحلي، وتحليل فرص تحقيق الدخل، وبناء موجزات SEO، وتوليد مسودات قابلة للمراجعة، وبوابة موافقة بشرية، ومحاكاة سير عمل غير ناشرة، وجسر تعلم محلي يحفظ الدروس والمهارات والتصحيحات.

## جسر التعلم المحلي

يعمل `core/mentor_bridge.py` كطبقة حفظ قابلة للتدقيق. يسجل الدروس المرشحة، ولا يرقّيها إلى معرفة معتمدة إلا بعد وجود قرار `approved` حقيقي في `core/approval_engine.py`. تُحفظ اللقطات وسجل الأحداث محليًا، بينما تظل مزامنة GitHub وتصدير أوزان النموذج معطلة.

الجسر لا ينسخ أوزان Manus أو أي نموذج مغلق. ما يمكن حفظه هو المعرفة المصرح بها، المهارات، قواعد العمل، نتائج الاختبارات، وسجل التصحيحات.

## التشغيل المحلي

شغّل من Windows:

```powershell
cd D:\Hermes
.\OrcaMax.bat
```

تعمل الواجهة محليًا على `http://127.0.0.1:7777` عندما تكون الخدمة قيد التشغيل. لا تربط الخدمة بعنوان عام.

## الاختبارات

الاختبارات المحلية الموجودة في `data/test_*.py` تشمل الموافقات، المحتوى، تحقيق الدخل، البحث، جسر التعلم، ومحاكاة سير العمل. يمكن تشغيل المجمع المحلي من داخل Hermes:

```powershell
cd D:\Hermes
python data\run_regression.py
```

## سياسة GitHub

يُستخدم GitHub كنسخة مصدرية خاصة عند تفعيل الخصوصية والصلاحيات المناسبة، وليس كخدمة تشغيل أو قاعدة بيانات لحالة Hermes. لا تُرفع النماذج المحلية، مفاتيح API، ملفات `.env`، سجلات الجلسات، طوابير الموافقات، لقطات الجسر، أو نتائج الاختبارات التشغيلية.

قبل كل دفع:

1. افحص الحالة والتغييرات.
2. افحص الأسرار النصية والمفاتيح والرموز.
3. تحقق من ملفات `.gitignore`.
4. ادفع المصدر والتوثيق والاختبارات المسموح بها فقط.
5. تحقق من محتوى المستودع بعد الدفع.

## حدود واقعية

Hermes مستقل محليًا، لكنه لا يمتلك أوزان نموذج Manus ولا يتعلم تلقائيًا من جلسة خارجية دون أن تُحفظ معرفة أو مهارة أو نتيجة اختبار مصرح بها. الجسر يحقق نقل الخبرة على مستوى artifacts قابلة للتدقيق، وليس نسخ النموذج نفسه.
